# Internationalization

## Setup

- `i18next` + `react-i18next`, resources bundled per namespace: `src/shared/i18n/locales/<lang>/<namespace>.json`
  (`common`, `errors`, `validation`, and one per feature).
- Language order: saved preference (MMKV) → best supported device locale (`react-native-localize`
  `findBestLanguageTag`) → fallback. Fallback is English unless `STACK.md` says otherwise.
- Initialise synchronously before the first render (resources are bundled, preference is in MMKV).
- Typed keys: declare `CustomTypeOptions` so a missing key is a TypeScript error.

## What gets translated

Everything a user sees or hears: buttons, titles, toasts, errors, empty states, validation messages, accessibility
labels and hints, notification text the app builds, permission explanations.

## Writing strings

- Never build sentences from pieces (`t('you_have') + n + t('items')`). Use interpolation and plurals:
  `t('cart.items', { count })` with `_one` / `_other` (and `_few` / `_many` where the language needs them).
- Keep punctuation and word order inside the translation.
- Dates, numbers, currency, lists: `Intl` with the active locale (`Intl.DateTimeFormat`, `Intl.NumberFormat`,
  `Intl.RelativeTimeFormat`). Never hand-format.
- Case changes: `toLocaleUpperCase(lang)` / `toLocaleLowerCase(lang)` (Turkish `i/İ`, `ı/I`). The `locale-aware-case`
  lint rule catches this.
- Identify languages by locale code (`tr`, `en-GB`, `pt-BR`), never by flag or country.

## RTL

If any supported language is RTL: `I18nManager.allowRTL(true)`; switching direction needs `I18nManager.forceRTL` and
an app reload, so tell the user and reload; use `start` / `end` styles instead of `left` / `right`; mirror
directional icons (back arrows), not logos or media controls.

## Language change in the app

Through the language bottom sheet (`rn-craft` → `references/patterns.md`): save to MMKV, `i18n.changeLanguage`, UI
updates without restart (except RTL direction changes). Tell the backend if it localises push or emails.

## CI

Fail the build on missing keys: compare every locale file to the fallback (a small script, or `i18next-parser`
with `failOnUpdate`), and on unused keys if the team wants it.
